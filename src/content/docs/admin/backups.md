## Веб-версия и сервер

Данные клиники на klinikon.online команда Klinikon копирует каждую ночь. Клинике для этого ничего делать не нужно.
Если программа для Windows подключена к серверу, данные клиники есть и там — после поломки компьютера
достаточно [установить программу заново и войти](/start/connect-computers/).

## Программа для Windows

Программа сама делает копию базы клиники раз в день и хранит её в `%APPDATA%\Serkor\backups`.
Копии хранятся неделю, и всегда не меньше семи последних.

Управление копиями — в <kbd>Профиль</kbd> → <kbd>Резервные копии</kbd>. Там видно, когда была
<kbd>Последняя копия</kbd>.

:::note
Раздел <kbd>Резервные копии</kbd> в профиле появился в версии, вышедшей после 1.2.0. В 1.2.0 копии
делаются так же каждый день, в ту же папку.
:::

### Второе место для копий

Копия на том же диске пропадёт вместе с диском. Поэтому выберите ещё одно место — другой диск или флешку.

1. В <kbd>Резервные копии</kbd> укажите <kbd>Папку для копий на другом диске или флешке</kbd>,
   например `E:\Klinikon`, или выберите диск в строке <kbd>Диски этого компьютера</kbd>.
2. Нажмите <kbd>Сохранить</kbd>.

Программа сразу запишет туда копию и будет писать каждую следующую. Если флешка не вставлена,
копия запишется, когда её вставят. Если выбрать папку на том же диске, где база, программа предупредит.

### Сделать копию сейчас

Перед важными изменениями нажмите <kbd>Создать копию сейчас</kbd>.

### Предупреждение «Нет резервной копии»

Если копии нет больше трёх дней, у всех сотрудников в верхней панели появляется красная отметка
«Нет резервной копии N дней». Проверьте, вставлена ли флешка, и нажмите <kbd>Создать копию сейчас</kbd>.

## Восстановить клинику из копии

1. <kbd>Профиль</kbd> → <kbd>Резервные копии</kbd> → <kbd>Восстановить из копии</kbd>.
2. Выберите копию из списка — в нём копии из обоих мест.
3. Нажмите <kbd>Восстановить</kbd>. Текущие данные программа сначала сохранит отдельно.
4. Войдите учётной записью, которая была в этой копии.

:::caution
На компьютере, подключённом к серверу, восстановление из копии недоступно: клиника хранится на сервере.
Если данные на таком компьютере испорчены, установите программу заново и войдите — данные придут с сервера.
:::
