Страница <kbd>Аналитика</kbd> есть только у администратора клиники. Врачи её не видят.

## Выбрать период

Сверху выберите <kbd>Сегодня</kbd>, <kbd>Неделя</kbd>, <kbd>Месяц</kbd>, <kbd>Год</kbd> или свой <kbd>Период…</kbd>.
Список <kbd>Все врачи</kbd> оставляет показатели одного врача. Дни считаются по календарю клиники.

## Вкладки

- **<kbd>Доходы</kbd>** — пациенты, приёмы, <kbd>Начислено</kbd>, <kbd>Оплачено</kbd> и <kbd>Не оплачено</kbd>,
  графики «Доход по дням» и «Приёмы по дням».
- **<kbd>Расходы</kbd>** — сумма расходов за период, самая большая статья, доля расходов в начисленном,
  график «Расходы по типам».
- **<kbd>Прибыль</kbd>** — доходы минус расходы; при убытке рядом появляется отметка «убыток».

Таблица <kbd>По врачам</kbd> показывает для каждого врача число приёмов, доход, средний чек и неоплаченное.

:::note
<kbd>Оплачено</kbd> считается по дню, когда деньги приняли. Платежи отменённых визитов в аналитику не входят.
:::

## Записать расход

1. Нажмите <kbd>Добавить расход</kbd>.
2. Укажите <kbd>Тип расхода</kbd> (например, аренда или материалы), <kbd>Сумму</kbd> и <kbd>Дату</kbd>.
3. Для регулярных платежей включите <kbd>Повторяющийся расход</kbd> и выберите, <kbd>Как часто</kbd>:
   ежедневно, еженедельно, ежемесячно или ежегодно.
